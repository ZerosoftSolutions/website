# ZeroSoft Solutions — Marketing Website

Static marketing site for **ZeroSoft Solutions LLC** (zerosoftsolutions.com).
Plain HTML/CSS, no build step. Deployable to any static host.

## Structure
```
index.html          Home page
src/
  services.html     Services
  terms.html        Terms of Service
  privacy.html      Privacy Policy
  site.css          Styles (Montserrat, brand palette)
assets/
  logo-*.svg        Logo kit (icon, white, mono, full lockup)
  favicon.svg       Browser-tab icon
```

## Brand
- Font: Montserrat. Colors: `#1B3D2E` green, `#222629` charcoal, `#6B7280` slate, `#F5F5F5` off-white.
- Logo: `⟨Z⟩` mark + ZEROSOFT SOLUTIONS wordmark.

## Deploy
Any static host works (GitHub Pages, Cloudflare Pages, Netlify). Serve this folder as the site root.
